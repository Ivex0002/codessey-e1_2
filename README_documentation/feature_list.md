# 자연수 응답이 기대될때 잘못된 응답이 올 경우 메시지를 출력
def check_int_user_input(max_number: int, min_number: int = 1):
    while True:
        user_input = input("선택: ").strip()

        if not user_input.isdigit():
            print("❌ 숫자로만 입력해주세요")
            continue

        int_value = int(user_input)
        if min_number <= int_value <= max_number:
            return int_value

        print(f"1 ~ {max_number} 사이의 숫자로 입력해주세요.")
```
선택 로직의 경우 위와 같이 구성하였기 때문에 `0` 입력시 특수 이벤트로 취급되도록 설정했습니다.

이로써 개발자 입장에서는 특수 케이스를 다룰때 매번 새로운 분기점을 만드는 것이 아니라, `check_int_user_input(max, min=1)` 형태에서 `min` 값만 조절하여 간단히 구현이 가능합니다

### 3. 퀴즈 추가

```
def user_input_quiz(is_new: bool):
    msg = "\n--- 새로운 퀴즈 등록 ---" if is_new else "\n---수정 항목을 입력해주세요---"
    print(msg)
    keys = [field.name for field in fields(Quiz)]

    new_quiz_data = {}

    for key in keys:

        msg = prompt_msg(key)

        match key:
            case "question" | "hint":
                value = input(f"▶ {msg}: ").strip()
            case "choices":
                choices_row_data = input(f"▶ {msg}: ").strip()
                value = [
                    opt.strip() for opt in choices_row_data.split(",") if opt.strip()
                ]
            case "answer":
                print(msg)
                value = check_int_user_input(len(new_quiz_data["choices"]))

        new_quiz_data[key] = value
    print("-" * 30)

    ensure_user_input_new_quiz(new_quiz_data, keys)

    return Quiz(**new_quiz_data)
```
퀴즈 하나를 유저 입력으로 받는 파트의 경우 업데이트 항목에 재활용이 가능하므로 약간의 수정 후 재활용 했습니다

호출시 단순하게 새로운 퀴즈 입력인지 True/False 항목을 받아 문구만 다르게 출력해줍니다

리턴값은 두 경우 모두 동일하게 유저에게 입력받은 `Quiz` 객체 1개 입니다

```
def add_quiz(quizzes: List[Quiz]):
    while True:
        print("퀴즈 등록 메뉴입니다")
        add_quiz_menu = ["새로운 퀴즈 등록", "현재 퀴즈 목록 확인", "종료"]

        user_input = choice(add_quiz_menu)

        match user_input:
            case 1:
                new_quiz = user_input_quiz(True)
                quizzes.append(new_quiz)
                print("\n--- 새로운 퀴즈가 등록 되었습니다 ---")
                last_idx = len(quizzes) - 1
                added_quiz = quizzes[last_idx]
                print(f"{last_idx+1}번 : ", end="")
                check_a_quiz(added_quiz)
                return
            case 2:
                check_quizzes(quizzes)
            case 3:
                print("퀴즈 등록을 종료합니다")
                break
```
새로운 퀴즈를 등록하는 화면입니다

위에서 언급한 `user_input_quiz`를 사용하여 퀴즈 하나를 입력받고, 인자로 등록된 `quizzes` 배열의 끝에 새로운 퀴즈를 붙여주는 역할입니다

### 4-1. 퀴즈 1개 확인 함수
```
def check_a_quiz(quiz: Quiz):
    question, choices, answer, hint = quiz.to_dict().values()
    print(question)
    choices_text = ", ".join([f"{idx}번-{item}" for idx, item in enumerate(choices, 1)])
    print(f"답안 : {choices_text}")

    print(f"정답 : {answer}번")

    print(f"힌트 : {hint}")
    return
```
- 퀴즈 1개를 확인하는 함수입니다. 이렇게 분리한 이유는 단일 퀴즈 확인 함수가 퀴즈 삭제, 퀴즈 등록에서 재사용 가능하다고 보았기 때문입니다

### 4-2. 모든 퀴즈를 확인하는 함수
```
def check_quizzes(quizzes: List[Quiz]):
    print("===현재 퀴즈 목록===")
    print(f"총 {len(quizzes)}개의 문제가 등록되어 있습니다")
    for idx, item in enumerate(quizzes, 1):
        # 줄바꿈을 막기 위해 end="" 사용
        print(f"\n{idx}번 문제 : ", end="")
        check_a_quiz(item)
    return

### 6-1. 비정상 종료 대응
`def run(self):` 함수에서 `try-except` 구문을 이용해 간단히 작성했습니다
```
def run(self):
        try:
            while True:
                (중략)

        except (KeyboardInterrupt, EOFError):
            print("\n\n프로그램 종료 요청이 감지되었습니다.")
            print("데이터를 저장하고 종료합니다.")

            try:
                self.save_data()
                print("데이터 저장이 완료되었습니다.")
            except OSError as e:
                print(f"데이터 저장에 실패했습니다: {e}")

            print("프로그램을 종료합니다.")
```
이로써 ctrl+c로 직접 탈출하더라도 안전하게 데이터 저장 후 종료되게 구성했습니다
