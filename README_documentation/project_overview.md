# 프로젝트 개요

## 1. 프로젝트 소개

Python을 활용하여 제작한 콘솔 기반 퀴즈 게임입니다

사용자가 객관식 퀴즈를 풀고 점수를 획득하는 기본적인 기능부터, 직접 퀴즈를 추가하거나 삭제하고 풀이 기록을 관리하는 기능까지 구현했습니다

단순한 퀴즈 풀이에 그치지 않고, 사용자가 원하는 방식으로 문제를 풀 수 있도록 랜덤 출제, 문제 수 선택, 힌트 기능 등을 추가했습니다

## 2. 주요 기능

- **퀴즈 풀이**: 등록된 문제를 순서대로 또는 무작위 순서로 출제합니다.
- **문제 수 선택**: 한 번의 게임에서 풀 문제의 개수를 직접 설정할 수 있습니다.
- **힌트 기능**: 문제 풀이 중 힌트를 확인할 수 있으며, 사용 시 점수가 차감됩니다.
- **퀴즈 관리**: 새로운 문제를 등록하거나 기존 문제를 삭제할 수 있습니다.
- **점수 관리**: 게임 결과를 바탕으로 최고 점수를 갱신하고 관리합니다.
- **풀이 기록 저장**: 각 게임의 시작 및 종료 시각, 풀이 문제 수, 획득 점수를 기록합니다.
- **데이터 장기 저장**: JSON 파일을 활용하여 퀴즈와 점수 등의 데이터를 저장하고 다음 실행 시 불러옵니다.

## 3. 구현 특징

- **객체지향 설계**: `QuizGame` 클래스를 중심으로 게임의 상태와 주요 기능을 관리합니다.
- **데이터 클래스 활용**: Python의 `dataclass`를 활용하여 퀴즈와 게임 세션 데이터를 간결하게 정의했습니다.
- **기능별 모듈 분리**: 데이터 클래스, 게임 로직, 공통 유틸리티를 디렉토리별로 분리하여 코드의 재사용성과 유지보수성을 고려했습니다.
- **JSON 데이터 관리**: `json` 모듈을 활용하여 프로그램의 데이터를 파일 형태로 저장하고 불러옵니다.
- **입력값 검증**: 공통 입력 검증 함수를 구현하여 잘못된 사용자 입력에 대응하고, 특수한 입력 범위에도 재활용할 수 있도록 구성했습니다.

## 4. 개발 목표

이번 프로젝트의 목표는 Python의 기초 문법을 실제 프로그램에 적용하고, 기능별 책임을 분리하여 하나의 프로그램을 구조적으로 설계하는 경험을 쌓는 것입니다.

특히 데이터 구조 설계, 모듈 간 의존성 관리, 파일 입출력, 사용자 입력 검증 및 데이터 저장과 같은 프로그래밍의 기본적인 요소들을 직접 구현하는 데 중점을 두었습니다.
